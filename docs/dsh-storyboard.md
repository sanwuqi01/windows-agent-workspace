# DSH 整期科普分镜入口

用户在 Win 11 项目里说“根据这期科普做代码分镜”时，读取当前期已定稿的口播正文，调用 `medical-motion\plan.cmd`。使用该期任务或打标清单对应的正文，保留原标题和期号。多期素材中无法确定指哪一期时，列出可选期号。输出放在该期任务输出下的独立动效目录。

```bat
medical-motion\plan.cmd "<本期完整正文.txt>" "<本期输出>\代码分镜"
```

DSH 根据内容选择适合用图形表达的步骤、对比、时间变化或原文给出的数量关系。每镜保留原句、字符位置、视觉说明、时长，以及生成的 HTML 和无声 MP4。可视化不能增加医学诊断、疗效、因果关系或数字。不适合插镜的段落保留口播画面。对时使用本期最终字幕。

## 同一期也需要筷子 AI 空镜时

先做一次混合规划。DSH 将代码分镜与筷子候选分配给不同原文片段。只要求规划时，到第一条命令即结束。

```bat
medical-motion\plan.cmd "<本期完整正文.txt>" "<本期输出>\混合分镜" --mixed --plan-only
medical-motion\plan.cmd "<本期完整正文.txt>" "<本期输出>\混合分镜" --resume
```

在生产机现有筷子技能目录运行下列命令，从同一份计划生成 `generate.mjs batch` 可读的数组。用任务已配置的 Node 执行。空数组表示本期没有合适的筷子候选。

```bat
node storyboard.mjs plan "<本期完整正文.txt>" --shots "<本期输出>\混合分镜\storyboard.json" --out "<本期输出>\筷子计划.json"
```

DSH 将每条 AI 空镜的原句忠实压成一句，再写一个不超过 15 字、能画出来的机制或物象锚点。生成器拼出以下提示词：

> <口播原句压成一句>，<≤15字机制锚点>。生成合适的3D医学科普动画，画面里不要出现任何文字。

写实空景改用“写实摄影空镜”，同时写明“画面里不要出现人物”。不要加入摄影术语、色调或画幅。按现有筷子流程审阅后再提交，新主题先出一条，抽帧检查烧字、人物和画面能否说明原句。整稿规划和 OpenMotion 渲染都不会提交筷子付费任务。

若用户仅要求筷子空镜，DSH 直接读整稿并写一个含 `kuaizi_shots` 数组的 JSON，各项填写 `source_sentence`、`summary`、`anchor` 和 `style`（`medical3d` 或 `warmReal`）。仍用上述 `--shots` 命令编译，跳过代码动效规划和渲染。

独立运行原有的 `storyboard.mjs plan 文稿` 仍可从全文提取粗选候选。正式混合任务使用上面的 `--shots`，使最终提示词沿用 DSH 对原文的压缩和机制判断。[代码动效参数与产物](../medical-motion/README.md)
