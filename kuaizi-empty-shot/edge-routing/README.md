# 筷子素材中心选页修复

生产适配器留在 Windows。本目录保存已部署修复的增量、补丁前后文件摘要和独立副本重建工具，不包含登录适配器源码、浏览器资料或任务日志。

**DSH 操作约定：** 先在现有适配器目录运行 `node generate.mjs probe`（旧命令 `check` 也是只读探针）。只使用当前 Edge 中唯一的 HTTPS 筷子素材中心；零个、多个、浏览器不对、页面报错时停止并反馈，不猜网址、不打开或重启浏览器，不提交生成任务。此探针不验证生成 API 或账号额度。

对已有生产适配器或修改前的备份运行 `python verify_patch.py "<适配器目录>"`，只读核对。加 `--output "<不存在的新目录>"` 可在工作目录以外重建两个文件。源版本无法识别会停止。此操作不会安装或修改运行中的模块。

此前 Windows 验收：已有素材中心和首页时正确连接素材中心；仅有首页时停止，未导航。DSH 通过自然语言检查取得现有页面 HTTP 200；这个结果不代表所有网站端 404 已消失。
